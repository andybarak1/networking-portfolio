# CCNA1 – Módulo 2 – Sesión 1: Sistemas Operativos en Redes

## Objetivo de la sesión
Comprender qué es un sistema operativo en redes, cuáles son sus componentes principales y por qué es fundamental para la administración de dispositivos de red.

---

## Conceptos clave
- Sistema operativo
- Kernel
- Shell
- CLI
- GUI
- Cisco IOS
- Consola
- Telnet
- SSH

---

## Explicación simple

Un sistema operativo es el software que permite que un dispositivo funcione y que el usuario pueda interactuar con él.

En redes, el sistema operativo permite administrar routers, switches y otros dispositivos.

### Componentes principales
- **Kernel**: parte del sistema operativo que interactúa directamente con el hardware.
- **Shell**: interfaz que permite al usuario comunicarse con el sistema operativo.

### Tipos de shell
- **CLI**: interfaz de línea de comandos. Se usan comandos escritos.
- **GUI**: interfaz gráfica de usuario. Se usan menús, ventanas e íconos.

---

## Explicación técnica

El sistema operativo de red administra recursos críticos del dispositivo como CPU, memoria, almacenamiento y acceso a interfaces. En el caso de Cisco, el sistema operativo más común es **Cisco IOS**, utilizado en routers y switches.

### Funciones principales de un sistema operativo de red
1. Gestión eficiente de recursos.
2. Configuración y personalización de dispositivos.
3. Mantenimiento y actualizaciones.
4. Seguridad de la red.

### Métodos de acceso a dispositivos
- **Consola**: acceso físico fuera de banda.
- **Telnet**: acceso remoto inseguro.
- **SSH**: acceso remoto seguro y cifrado.

---

## Modelo mental

- **Sistema operativo** = cerebro del dispositivo
- **Kernel** = controla hardware
- **Shell** = puerta para que el usuario dé órdenes
- **CLI** = precisión
- **GUI** = comodidad
- **SSH** = acceso remoto seguro
- **Telnet** = acceso remoto inseguro

---

## Diferencias importantes

### Kernel vs Shell
- Kernel = maneja hardware
- Shell = interfaz con el usuario

### CLI vs GUI
- CLI = más potente, rápida, precisa y automatizable
- GUI = más visual, más simple para principiantes, pero más limitada

### Telnet vs SSH
- Telnet = remoto pero inseguro
- SSH = remoto, seguro y cifrado

---

## Ejemplos prácticos
Cuando en Packet Tracer se entra a un router y se escriben comandos, se está usando:
- la **shell**
- mediante una **CLI**
- sobre el sistema operativo **Cisco IOS**

---

## Errores típicos
- Confundir kernel con shell.
- Creer que GUI y CLI hacen exactamente lo mismo.
- Pensar que Telnet es seguro.
- Creer que Cisco IOS es lo mismo que iOS de Apple.

---

## Resumen final

En redes, el sistema operativo es esencial porque permite administrar y proteger los dispositivos.  
El **kernel** controla el hardware, la **shell** permite interactuar con el sistema y en Cisco el sistema operativo principal es **Cisco IOS**.  
La **CLI** es la herramienta más importante para administración real de red.  
Para acceso remoto seguro se utiliza **SSH**.
